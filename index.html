Firebase 연결이 필요해요

여러 태블릿이 같은 그림을 실시간으로 주고받으려면 Firebase Realtime Database가 필요합니다.

  1. Firebase 콘솔에서 프로젝트를 열고 Realtime Database를 만듭니다.
  2. 프로젝트 설정 → 내 앱(웹)의 설정값을 이 HTML 파일 위쪽 firebaseConfig에 붙여 넣습니다.
  3. databaseURL 값이 들어 있는지 확인합니다.
  4. 파일을 저장하고 다시 열면 시작 화면이 나옵니다.
